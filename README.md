# 《爱情证书》— 纯代码 16-bit 掌机恋爱养成风像素 MV

为孙燕姿经典曲目 **《爱情证书》(2000)** 量身打造的 **100% 纯代码渲染（零生图、零第三方前端依赖）** 16-bit 暖色系掌机恋爱养成风横屏（`1920×1080`, `30fps`）像素 MV 工程。

## 核心特性

- **100% 纯代码像素引擎**：原生 `320×180`（`16:9`）软件帧缓冲，通过 `Bayer 4×4` 有序抖动（Ordered Dithering）实现正统 SFC / GBA 16-bit 暖霞渐变、光束与场景切换过渡，最终通过 `FFmpeg` 最近邻整数倍放大 `6×` 至 `1920×1080`，每一颗像素边缘 100% 锐利无模糊。
- **手绘级矩阵像素小人（Chibi Sprites）**：纯字符矩阵定义短发女主 **小姿**、男主 **阿远** 与校园橘猫 **小橘**，支持呼吸眨眼、4 帧行走循环、托腮自习、撑伞看翻盖手机、书桌写信、冬日红围巾呵气、天台吹口琴及重逢同框等丰富动作。
- **纯 1-bit 点阵中文字体渲染**：内置解析开源 [Fusion Pixel Font（缝合像素字体）](https://github.com/TakWolf/fusion-pixel-font) `8px / 10px / 12px` `.bdf` 位图字库，彻底告别抗锯齿发虚。
- **真实音频包络驱动**：从无损 `.flac` 提取 30fps RMS 能量与高频包络，实时驱动右上角 5 段像素频谱、图书馆暖阳强度与间奏口琴音符律动。

## 目录结构

- [`src/pixelCanvas.js`](src/pixelCanvas.js)：`320×180` 纯软件像素画布、Bayer 抖动渐变、暖光光束与 RPG 窗口皮肤
- [`src/bdfFont.js`](src/bdfFont.js)：`.bdf` 纯 1-bit 位图字体解析与像素描边/投影渲染器
- [`src/sprites.js`](src/sprites.js)：纯代码像素小人（小姿、阿远、橘猫小橘）、表情气泡、像素雨伞与纸飞机矩阵
- [`src/lyrics.js`](src/lyrics.js)：《爱情证书》精确时间轴、RPG 课程提示与学分/距离曲线
- [`src/scenes.js`](src/scenes.js)：9 大像素场景绘制、顶部学分/距离/频谱 HUD 与底部头像歌词对话框
- [`src/render.js`](src/render.js)：CLI 渲染入口（支持一键导出 `1920×1080` MP4 或分镜预览图）

## 本地运行与重新渲染（Windows / macOS / Linux）

只需安装 [Node.js](https://nodejs.org/) 与 `ffmpeg`（无需 `npm install` 任何第三方包）：

```bash
# 生成 11 张分镜关键帧预览 PNG（输出至 preview_frames/）
node src/render.js --preview

# 渲染完整 1920x1080 MP4 视频（默认自动读取 assets/audio/ 下的音频，也可手动指定路径）
node src/render.js --audio "E:\BaiduNetdiskDownload\爱情证书\爱情证书.flac"
```
